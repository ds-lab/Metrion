# METRION — A Framework for Accurate Software Energy Measurement 

METRION is a modular, platform-agnostic framework for thread-level application energy attribution on CPU and DRAM, accounting for SMT, frequency scaling, and multi-socket/NUMA.

The source code is temporarily unavailable because it is going through our project’s formal release workflow. If required for the review process, we will explore whether confidential access can be arranged.
